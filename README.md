# Elza Bērziņa — portfolio

Multimediju mākslinieces Elzas Bērziņas portfolio mājaslapa.

Lapa: https://erzabelzina.github.io/

## Struktūra

- `index.html` — visa lapa (HTML, CSS un JavaScript vienā failā)
- `images/` — darbu attēli, video, portrets, favicon un `og-image.jpg`
- `robots.txt`, `sitemap.xml` — meklētājprogrammām

## Kā pievienot darbu

`index.html` meklē `REDIĢĒT 1`, sarakstā `IMAGES` pievieno jaunu ierakstu ar `src`, `title`, `titleEn`, `desc`, `descEn` un `more` (papildu attēli un video).
